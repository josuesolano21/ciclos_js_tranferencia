### Haziel Josue Solano (Líder) - 3 Ejercicios

### Sara Rojas Estupiñan - 3 Ejercicios
* **Ejercicio 1 – Números primos:** Algoritmo que muestra todos los números primos del 1 al 50 utilizando ciclos y condicionales.

* **Ejercicio 6 – Juego del adivinador:** Generación de un número aleatorio (1-20) donde el usuario debe adivinarlo mediante pistas de "mayor" o "menor" en cada intento fallido.
